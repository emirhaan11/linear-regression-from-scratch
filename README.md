# Linear Regression from Scratch

Just a simple implementation of Linear Regression using NumPy.

I built this to practice the math behind the algorithms (Cost Function, Gradient Descent).

**Note:**
I wrote this code mainly to reinforce what I learned after completing **Andrew Ng's Machine Learning Specialization** on Coursera. It's a personal practice repo to make sure I understand the underlying concepts.

**Files:**
- `model.py`: The manual implementation of the class.
- `test.ipynb`: Testing the model with some dummy data to see if it converges.
